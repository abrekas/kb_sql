Очень безопасный сайт, на котором *__точно__* нет sql-инъекции.

## Запуск: ##
```
npm install
npm run
```

## Как сломать: ##
Стандартная sql-инъекция, где ввод пользователя без изменения вставляется в sql-запрос, поэтому можно вписать `' OR '1'='1` и запрос выведет реальную строку из бд, поэтому авторизация пройдёт.  
Однако чтобы сделать ввод нужно будет постараться и помучаться :)
