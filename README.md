Очень безопасный сайт, на котором *__точно__* нет sql-инъекции.  
https://strong-chaja-08973d.netlify.app/  (работает только с впн)

## Как сломать

Стандартная sql-инъекция `' OR'1'='1` сработает, потому что ввод пользователя без изменений вставляется в sql-запрос. А авторизация выполняется если этот запрос вывел какую-то строку из бд (даже не обязательно admin). При `' OR'1'='1` условие на WHERE всегда будет верным, поэтому вернётся вся таблица users, и оттуда берётся первая строка (rows[0]).

Однако чтобы ввод выполнить нужно будет постараться и помучаться :)
